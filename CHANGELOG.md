# Changelog

## Unreleased

### Physics built from open sources (see `docs/PUBLIC_REFERENCES.md`)
- **Generic medium-range missile** (`env.missile_model = "generic_mraam"`, default): 3-D point
  mass with boost–sustain motor and mass loss, Mach-dependent drag plus induced drag,
  dynamic-pressure manoeuvre limit, pure PN with autopilot lag, loft, datalink or inertial
  midcourse, active seeker (A-pole), closest-approach fuze and explicit miss causes. Notional
  parameters; the 2.0 missile remains as `"legacy"`.
- **U.S. Standard Atmosphere 1976** (`atmosphere.rs`).
- **Flyout-derived WEZ**: `Rmax` / `Rnez` looked up in a table generated by flying the missile
  over shooter altitude, target altitude, target aspect and off-boresight
  (`examples/gen_wez.rs`, `data/wez_generic_mraam.json`), with a test keeping it in sync. The
  observed WEZ now matches launched missiles within about 10–20% in every recipe cell (it was
  off by more than a third in 7 of 9).
- **Aircraft energy** (`env.aircraft_model = "energy"`, default): speed bleeds with load factor
  and climb and recovers toward the altitude's top speed; `"constant_speed"` restores 2.0.
- **Missile warning**: aircraft know the bearing of an active missile tracking them; scripted
  pilots defend on it.
- **A-pole / F-pole**: `SimEvent.pole_nm` on pitbull, hit and miss events; missile snapshots
  carry Mach and flight phase.
- **Reference pilots** (`configs/reference`, `make_env(opponent="ref_*")`) built from open BVR
  principles and validated by cross-play.
- `docs/PUBLIC_REFERENCES.md`: the source of every model element.
- Lab: dark theme (auto / light / dark), missile model and support switches, range card and
  missile parameters in the WEZ tab, Mach labels on missiles, A-pole and F-pole in the event log.

### Added
- **B-ACE Lab**: the simulator compiled to WebAssembly (`crates/bace-wasm`) with a browser
  workbench: scenario builder, 2D tactical display, playback, telemetry, observation inspector,
  cross-play evaluation with bootstrap CIs, WEZ validation, FSM search and an environment self-test.
- Event stream on every step (`StepResult.events`): launch, pitbull, hit, miss, track gained/lost,
  end. Recorded in episode files.
- Richer snapshots: simulated time, WEZ/threat values per track, behavior, mission, objective,
  cumulative reward breakdown per aircraft. All new fields default when loading older recordings.
- `EnvConfig.missile_support`: `"track"` (default: datalink updates need the shooter's track)
  or `"launch"` (2.0: perfect updates from launch).
- `TeamConfig.beh_noise` (opt-in FSM decision noise) and `FsmParams.beh_noise` / `spawn_jitter_nm`.
- `bace.record.EpisodeRecorder` and `NativeEnv.set_keep_frames` / `frame_json`.
- `ScenarioConfig::from_partial_value`.
- CI job for the web layer and a GitHub Pages workflow.

### Fixed
- **Dashboard did not load**: `CombatScene._lights()` / `_theater()` were removed in `db96d55`.
- **Observation leak**: undetected enemies exposed their true distance to goal (`dist_target`).
  Their aspect placeholder no longer depends on own heading.
- **`run_experiment` spawned red on top of blue** when a case gave a partial `red` block (the
  README example): partial cases are now merged over the full defaults.
- **Scripted FSM never cranked, supported or broke away.** The offset side followed the sign of the
  current aspect, so it flipped every decision and the aircraft kept the threat on its nose, also
  while "evading". The side is now latched per engagement, break turns away (B-ACE 1.0), the shot
  is checked before the break with a short commit window, breaks are held 8 s, and the crank
  trigger is the threat factor as in B-ACE 1.0.

- **Tests and benchmarks overwrote `configs/baselines/*.json`**: `run_fsm()` only writes profiles
  with `write_baselines=True` (the `bace.experiment fsm` CLI sets it for non-smoke runs).

- The WEZ recipe summarized the *first* range where hits fell below 50%, so a minimum-range miss
  could hide the real outer edge; it now uses the outer crossing.

### Changed
- Defaults changed to the new physics (`generic_mraam`, `track`, `energy`). For 2.0 physics set
  `{"missile_model": "legacy", "missile_support": "launch", "aircraft_model": "constant_speed"}`.
- `baseline1` behaviour changed with the fix above. Results produced with the previous FSM, and the
  profiles in `configs/baselines/` (searched against it), should be regenerated.
- `bace-vec` has a `native` feature (default) for threads and recording; without it, recipes run
  sequentially (used by the WebAssembly build).
